# Архивный макет MigreBot

Первый вариант приветственного экрана, 1440 × 1040 px. Сохранён как отдельная дизайн-концепция.

| Файл | Содержимое |
| --- | --- |
| `MigreBot-welcome.png` | Растровое превью |
| `MigreBot-welcome.svg` | Векторный макет |
| `layout.json` | Геометрия, стили и текст слоёв |
| `code.js` | Импортёр слоёв через Figma Plugin API |

Импортёр создаёт отдельный фрейм с текстовыми слоями и фигурами. Требуется окружение локального плагина Figma Design. Auto Layout и интерактивные переходы не предусмотрены.
